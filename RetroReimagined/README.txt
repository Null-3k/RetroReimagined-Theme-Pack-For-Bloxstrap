Installation Guide
Replace the "content", and "ExtraContent" folder which is already in Bloxstrap\Modifications with the folders under the main theme file (This refers to the "content", and "ExtraContent" file which is in the theme set, which will be used to replace the ones in the Modifications folder). You can get to the Modifications folder by opening the Bloxstrap application and then going to "Configure settings", then go to the mods section and there should be a button with "Open Mods Folder" said on it, click it. Though only "content" file is mainly important

I try to update this whenever there is an unexpected error with the set or due to compatibility issues, you can get newer versions at https://github.com/Null-3k/RetroReimagined-Theme-Pack-For-Bloxstrap
